## Music

The YouTube source URL you provided is not a direct audio-file URL, so it is not embedded as an audio source in the page.

For the background music button:
- legally obtain/use the audio you want
- rename it to `music.mp3`
- put it inside `assets/`

The button will then play/pause it.

## Deploy to GitHub Pages

Upload all files/folders to a GitHub repository and enable:
Settings → Pages → Deploy from branch → main → / (root).

The page is static and needs no server.

## Wishes

The guest-wishes feature uses browser localStorage in this version. That means wishes are stored on each visitor's own device. For one shared guestbook visible to everyone, a backend/database such as Firebase or Supabase is required.
